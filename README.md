# Bank Management System

A Java-based desktop banking application developed to manage basic banking operations through a simple graphical interface. The project uses MySQL for database connectivity and storage.

## Features

- User registration and login
- Account creation and customer management
- Deposit and withdrawal
- Fast Cash
- Balance enquiry
- PIN change
- Transaction statement
- MySQL database integration

## Technologies Used

- Java
- Java Swing / AWT
- MySQL
- JDBC
- Eclipse IDE



## How to Run

- Clone or download this repository.
- Open the project in Eclipse or another Java IDE.
- Configure the MySQL database connection in connect.java.
- Add the required JAR files from the jar folder to the project.
- Run main_Class.java.
